# Development voltage recipes

These recipes are loaded by the Gradle development runs and are not included in the published jar.

- Lime wool -> lime dye: 32 EU/t (LV)
- Yellow wool -> yellow dye: 128 EU/t (MV)
- Red wool -> red dye: 512 EU/t (HV)

All three use the Modern Industrialization electrolyzer and run for 200 ticks before overclocking.
